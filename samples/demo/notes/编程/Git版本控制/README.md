# 📓 Git 版本控制 · 学习笔记库

基于 Fireship 频道的两部视频 **《Git It? How to use Git and Github》**（12:19）与 **《13 Advanced (but useful) Git Techniques and Shortcuts》**（8:06）整理的 Obsidian 笔记库。

> [!important] 数据来源声明
> 本库基于 YouTube 官方元数据与官方章节 + 平台自动字幕（video_ingest.py 抓取，2026-11-07 核对）整理。
> 笔记已整理为中文；由模型 glm-5.3-flash 按本技能模板生成，细节以视频为准。
> 如发现笔记与视频不符，以视频描述栏与官方章节为准。

> [!tip] 如何打开本库
> 1. 打开 Obsidian → 左下角 **管理仓库（Manage vaults）**
> 2. **打开文件夹作为仓库（Open folder as vault）** → 选择本文件夹
> 3. 从 [[00-Home]] 开始
