# ch10 钩子、清理与快速切换

> [!info] 视频位置
> [6:18 Hooks](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=378s) · [6:58 Destroy Things](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=418s) · [7:41 Checkout to Last](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=461s)

## 🎯 本章目标
看完本章，你会用 Git 钩子（hooks）自动把关代码质量，掌握「fetch + reset --hard + clean」的安全重置流程，并能一键切回上一个分支。

## 🔗 钩子 Hooks：在 Git 事件前后自动执行脚本

- Git 会在你执行某些操作（如 commit）时产生事件，钩子允许你在事件发生**之前或之后**运行自定义代码（[6:18](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=378s)）。
- 钩子脚本位于隐藏的 `.git` 目录下的 `hooks` 文件夹，里面有一批预先写好的脚本模板，配置后可在不同 Git 事件发生时运行（[6:18](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=378s)、[6:40](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=400s)）。
- JavaScript 开发者可以用 **husky** 这个 npm 包大幅简化钩子配置：安装后可创建脚本，在每次 commit 前校验或 lint 代码，帮助提升整体代码质量（[6:40](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=400s)）。

## 🧨 Destroy Things：把本地重置回远程状态

当你本地改得一团糟，想彻底回到与 GitHub 远程仓库一致的状态时，按以下步骤操作（[7:02](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=422s)）：

1. `git fetch` —— 先抓取远程仓库的最新代码。
2. `git reset --hard` —— 用远程代码**强制覆盖**本地代码。⚠️ 作者提醒：本地改动将**永久丢失**（lost forever），操作前务必确认。
3. `git clean` —— reset 之后可能还残留一些**未跟踪文件**或构建产物，用 clean 命令一并清除。

> [!quote] 作者原话
> "Be careful — your local changes will be lost forever."（小心——你的本地改动会被永久丢失）（[7:02](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=422s)）

如果干脆受够了 Git，作者还开了个玩笑：想彻底删掉版本控制（比如改用 Apache Subversion），只需删除那个隐藏的 `.git` 文件夹即可（[7:23](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=443s)）。

## 🔀 一键切回上一分支

刚切出某个分支却忘了它的名字？直接用：

```bash
git checkout -
```

`-` 会带你直接回到上一个工作的分支，类似 shell 里的 `cd -`（[7:41](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=461s)）。这也是视频最后一个技巧，之后作者收尾并推荐他的完整 Git 课程。
