# ch06 快速提交与命令别名

> [!info] 视频位置
> [0:59 Combine add & commit](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=59s) · [1:20 Aliases](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=80s)

## 🎯 本章目标
用 `commit -am` 合并「暂存 + 提交」两步操作，再通过 `git config` 别名进一步缩短常用命令，减少重复敲键、加快日常提交。

## 用 `-am` 一步完成暂存与提交

平时我们学到的第一步通常是分开执行 `git add` 和 `git commit` 来保存代码快照。但视频指出有更好的做法：去掉 `git add`，直接用 `-am` 标志提交，它会==自动把当前工作目录下的所有文件加入暂存并提交==（[1:04](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=64s)）。

```bash
# 传统两步
git add .
git commit -m "message"

# 一步到位
git commit -am "message"
```

> [!warning] 注意
> `-a` 只会暂存**已被 Git 跟踪**的修改；新建的未跟踪文件仍需手动 `git add`。此细节以视频为准。

## 配置别名：把命令缩成两个字母

`git config` 提供创建别名（alias）的功能，常用于==缩短已有命令，或自定义新命令==（[1:25](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=85s)）。视频中给出的例子是创建名为 `ac` 的别名，让它执行 add + commit，这样只需两个字母就能完成提交。

```bash
git config --global alias.ac "commit -am"
# 之后就可以：
git ac "message"
```

## 提交流程演进步骤

1. 基础做法：`git add` + `git commit` 分两步执行（[0:44](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=44s)）。
2. 改进：改用 `git commit -am`，自动暂存当前目录下的文件，省掉 `git add`（[1:04](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=64s)）。
3. 更简：用 `git config` 配置别名 `ac`，两个字母直接完成 add + commit（[1:25](https://www.youtube.com/watch?v=ecK3EnyGD8o&t=85s)）。

| 方式 | 命令 | 效果 |
| --- | --- | --- |
| 传统两步 | `git add` + `git commit -m` | 手动暂存再提交 |
| `-am` 标志 | `git commit -am "msg"` | 自动暂存已跟踪文件的修改 |
| 自定义别名 | `git ac "msg"` | 两个字母完成提交 |
