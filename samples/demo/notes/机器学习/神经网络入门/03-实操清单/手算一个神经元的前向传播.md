# 🛠️ 手算一个神经元的前向传播

## 1️⃣ 准备输入与参数
- [ ] 画一张 4×4 的像素网格，每个格子填 0–1 的灰度值（0 黑、1 白），当作上一层激活值（验证：每个格子数值都在 0 与 1 之间）
- [ ] 为 16 个格子各写一个权重 w，用绿=正、红=负标记符号（验证：颜色与正负号一一对应）
- [ ] 自定一个偏置 b（建议先取 -10 这类明显的负数，便于观察阈值效果，以视频为准）

## 2️⃣ 加权求和并加偏置
- [ ] 把每个像素值与对应权重相乘，再全部相加：$z=\sum w_i a_i$（验证：求和项数 = 16，与格子数一致）
- [ ] 在和上加偏置：$z+b$（验证：手动重算一遍，两次结果相同）
- [ ] 观察规律：只有目标区域像素亮、周围像素暗且配负权重时，加权和才最大——这正是视频中“边缘检测”神经元的直觉（验证：把周围像素调暗，确认 z+b 变大）

## 3️⃣ Sigmoid 压缩得到激活
- [ ] 把 $z+b$ 代入 Sigmoid：$a=\sigma(z+b)=\frac{1}{1+e^{-(z+b)}}$（验证：结果落在 0 与 1 之间）
- [ ] 用极端输入自测：输入很大的正数时 a 接近 1，很大的负数时 a 接近 0（验证：分别取 $z+b=100$ 与 $=-100$ 各算一次）
- [ ] 调整偏置再算一遍：把 b 从 -10 改为 0，观察激活变大的效果——偏置决定“加权和要多高神经元才开始激活”（验证：同一输入下，b=0 的激活值 > b=-10 的激活值）

> [!warning] 避坑
> - 忘加偏置就直接过 Sigmoid——偏置是加在加权和之后、压缩之前的
> - 权重符号弄反：正权重想“点亮”的区域要配正权重，想抑制的周围像素配负权重
> - Sigmoid 输出超出 [0,1] 说明指数项算错了符号
> - 视频里的 -10 只是演示用的示例数值，勿照搬结论；真实网络参数由训练得出
