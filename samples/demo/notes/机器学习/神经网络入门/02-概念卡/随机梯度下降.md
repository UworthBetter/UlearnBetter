# 随机梯度下降

> [!abstract] 一句话定义
> ==把训练数据随机分成小批次，用每批的近似梯度代替全量梯度来更新参数，大幅加快学习速度。==

## 📌 是什么

- 全量梯度下降要求每一步都对**全部训练样本**求梯度再取平均，实际计算中这样做极其耗时——计算机逐个累加每个训练样本的影响要花非常长的时间（[9:33](https://www.youtube.com/watch?v=Ilg3gGewQ5U&t=573s)）。
- 常见做法是：先把训练数据**随机打乱**，再切成许多**小批次（mini-batch）**，视频举例每批约 100 个训练样本，然后按每个小批次计算一步更新。
- 小批次算出的不是代价函数的真实梯度（真实梯度依赖全部训练数据），因此不是"最有效率"的下坡方向，但它是相当好的**近似**，更重要的是带来巨大的计算加速（[10:00](https://www.youtube.com/watch?v=Ilg3gGewQ5U&t=600s)）。
- 视频的比喻：在代价表面上，随机梯度下降像"醉汉摇摇晃晃但步子很快地下山"，而不是"每步都精确计算方向、缓慢谨慎迈步的清醒人"（[10:00](https://www.youtube.com/watch?v=Ilg3gGewQ5U&t=600s)）。
- 反复遍历所有小批次并不断调整，最终会收敛到代价函数的一个**局部最小值**，即网络在训练样本上表现很好（[11:17](https://www.youtube.com/watch?v=Ilg3gGewQ5U&t=677s)）。

## 📌 执行顺序

1. 随机打乱全部训练数据。
2. 把数据切分成许多小批次（视频举例：每批 100 个样本）。
3. 对当前小批次，用反向传播算出每个样本对权重和偏置的期望微调，取平均得到近似梯度。
4. 沿该近似梯度方向做一步参数更新。
5. 换下一个小批次重复，直到遍历完所有批次。
6. 反复多轮遍历，网络收敛到代价函数的局部最小值。

## 🧩 在视频/系统中的角色

出现在 [[ch12 随机梯度下降]]。在视频的体系中，[[反向传播]] 只能告诉**单个训练样本**希望怎样微调权重和偏置，真正的梯度下降步本应对数万个样本求平均，代价太高；随机梯度下降就是把两者高效衔接起来的实践方案——让 [[梯度下降]] 在可承受的计算成本下真正跑起来，是整个"网络如何学习"流程落地的关键一步。

## ⚖️ 优点与局限

| ✅ 优点 | ⚠️ 局限 |
| --- | --- |
| 相比全量梯度有显著的计算速度提升 | 每步用小批次近似梯度，不是最精确的下坡方向（作者形容为"醉汉下山"） |
| 每个小批次仍是全量梯度的"相当好的近似" | 轨迹更随机摇摆；最终收敛的是局部最小值而非保证全局最优 |
| 让反向传播 + 梯度下降在数万样本规模的训练中切实可行 | 具体批次大小等参数以视频为准 |
