# 反向传播

> [!abstract] 一句话定义
> ==从输出层出发，逐层汇总每个训练样本对权重和偏置的期望微调，高效算出代价函数梯度的核心算法。==

## 📌 是什么

- 神经网络学习的核心算法：[0:04] 开篇即点明反向传播是“神经网络如何学习背后的核心算法”，本视频先做不含公式的直觉走查，数学细节留到下一视频（[0:04](https://www.youtube.com/watch?v=Ilg3gGewQ5U&t=4s)）。
- 它要解决的问题是：[1:45] 学习就是找到让代价函数最小的权重和偏置，而 [[梯度下降]] 需要代价函数的负梯度——反向传播正是**计算这个“极其复杂的梯度”**的算法（[1:45](https://www.youtube.com/watch?v=Ilg3gGewQ5U&t=105s)）。
- 梯度分量的含义：在约 13,000 维空间里无法直接想象梯度方向，但每个分量的大小表示**代价函数对该权重/偏置的敏感程度**——例如某分量 3.2 vs 0.1，意味着动前者的效果是后者的 32 倍（[2:11](https://www.youtube.com/watch?v=Ilg3gGewQ5U&t=131s)）。
- 直觉理解方式：对单个训练样本（比如一张"2"的图片），记录输出层希望各激活如何被微调（希望的目标神经元升、其余降，幅度与差距成正比），再逐层向前传导这些“期望”（[3:31](https://www.youtube.com/watch?v=Ilg3gGewQ5U&t=211s)）。
- 每个输出神经元都有自己对前一层的“期望”，按权重和所需变化量比例加权汇总，递归地向前重复此过程；对所有训练样本的期望微调取平均，就（大致）得到代价函数的负梯度（[8:44](https://www.youtube.com/watch?v=Ilg3gGewQ5U&t=524s)）。

## 🧩 在视频/系统中的角色

反向传播集中出现在 **[[ch11 反向传播直觉]]**，在网络学习体系中承担“梯度计算器”的职责：[[梯度下降]] 负责沿负梯度方向更新参数，而反向传播负责高效算出这个梯度本身。它与前后视频衔接——前面讲过 [[代价函数]] 与 [[梯度下降]]（系列第三个视频），后续数学推导与 [[随机梯度下降]] 则分别在下一视频与 [[ch12 随机梯度下降]] 展开。

## 📌 执行顺序

1. 前向传播输入（如手写数字"2"的 784 个像素），得到当前输出层激活。
2. 对输出层记录期望微调：目标神经元激活升高、其余降低，幅度与各值离目标的差距成正比。
3. 对每个输出神经元，从三条途径提高/降低其激活：调偏置、调权重、改变前一层激活；权重调整幅度与相连前一层的激活大小成正比。
4. 把所有输出神经元的“期望”按权重比例加总，形成对倒数第二层的一组期望微调。
5. 递归地对更早的层重复同样过程，逐层向后（向输入方向）传播。
6. 对所有训练样本重复上述流程，把各自期望的权重/偏置微调取平均，得到负梯度，供梯度下降使用。

## ⚖️ 优点与局限

| ✅ 优点 | ⚠️ 局限 |
| --- | --- |
| 高效计算复杂代价函数的梯度：把每个样本对全部权重/偏置的期望微调逐层汇总，而非盲目试探每个参数 | 严格来说要对每个梯度下降步遍历全部数万个训练样本，单步计算量大——所以才需要小批次技巧（后由随机梯度下降解决） |
| 各分量大小指示“性价比”：告诉你微调哪些权重最划算（最大的调整发生在最活跃神经元与期望激活神经元之间，类似 Hebbian 的“一起放电的神经元连在一起”） | 只对单个样本做反向传播会让网络偏向把所有图都判成那一类，必须对所有样本取平均才合理 |
| 机制本身直觉上不难理解，只是记号与下标追逐容易让人困惑（作者自述） | 视频本集刻意回避了定量公式，梯度只是“大致成正比”的负梯度，精确数学以视频及后续内容为准 |
