# 权重与偏置

> [!abstract] 一句话定义
> ==权重刻画神经元关注前一层的哪种像素模式，偏置决定加权和要多大才让神经元显著激活。==

## 📌 是什么

- 权重（weight）是前一层每个神经元与本层神经元连接上的一个数字；把前一层所有激活按权重求和，得到**加权和**，权重可以用绿色（正）/红色（负）像素网格来可视化 ([9:03](https://www.youtube.com/watch?v=aircAruvnKk&t=543s))。
- 想让第二层某个神经元检测某个区域的边缘，可以把该区域像素的权重设为正、周围像素设为负——这样当中间像素亮、周围暗时加和最大 ([9:31](https://www.youtube.com/watch?v=aircAruvnKk&t=571s))。
- 加权和可以是任意实数，但激活值需要在 0–1 之间，所以要把加权和经 Sigmoid 函数“挤压”到 0–1 ([10:28](https://www.youtube.com/watch?v=aircAruvnKk&t=628s))。
- 偏置（bias）是在加权和进入 Sigmoid 之前额外加上的一个数，例如 −10，用来要求加和大于某个阈值（比如 10）神经元才显著激活 ([10:52](https://www.youtube.com/watch?v=aircAruvnKk&t=652s))。
- 整个示例网络（784 输入 × 隐藏层 16 神经元等）共有约 13,000 个权重和偏置，学习就是找到让网络正确解决问题的一组合适取值 ([11:59](https://www.youtube.com/watch?v=aircAruvnKk&t=719s))。

加权和与激活的公式形式为：

$$a = \sigma\left(\sum_i w_i \, a_i + b\right)$$

其中 $w_i$ 是权重，$a_i$ 是前一层激活，$b$ 是偏置，$\sigma$ 是 Sigmoid 压缩函数。

## 📌 执行顺序

1. 取前一层所有神经元的激活值。
2. 按各自的权重做加权求和。
3. 在加和上加上偏置（例如 −10）。
4. 把结果送入 Sigmoid 等压缩函数，压到 0–1 区间。
5. 得到的值就是本神经元的激活值。

## 🧩 在视频/系统中的角色

权重与偏置出现在 [[ch03 边缘检测的期望]] 和 [[ch04 权重偏置与学习]]。它们是网络中全部可调节的“旋钮与旋盘”：权重决定第二层神经元在找什么像素模式（如边缘），偏置决定激活门槛。所谓“学习”，就是让计算机自动找到这约 13,000 个数字的合适设定，而不是靠人手工调整。作者强调理解这些数字的含义，是调试网络、挑战假设的起点。

## ⚖️ 优点与局限

| ✅ 优点 | ⚠️ 局限 |
| --- | --- |
| 表达力强：通过调节权重可让神经元捕捉任意像素模式，如边缘、图案等 | 数量庞大（示例网络约 13,000 个），无法靠人工手工设定出有效解 |
| 权重可按正/负网格可视化，帮助建立对网络行为的直觉，便于实验与改进结构 | 网络可能“看起来能用但原因与预期不符”，需要深入检查权重偏置才能验证假设（以视频为准） |
