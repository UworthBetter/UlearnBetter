# 代价函数

> [!abstract] 一句话定义
> ==把网络输出与目标输出之差的平方求和，再对全部训练样本取平均，得到衡量网络多“糟糕”的单一数值。==

## 📌 是什么

- 网络初始时权重和偏置全部随机初始化，输入一张手写的 3，输出层一团混乱——代价函数就是告诉计算机“这个输出很糟糕”的方式。[3:01–3:24](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=201s)
- **单个训练样本的代价**：把输出层每个激活值与目标值之差取平方再求和；网络自信地分类正确时这个和很小，网络“不知所措”时很大。[3:51](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=231s)
- **网络的代价**：对数万个训练样本的单样本代价取平均，作为衡量网络整体表现多差的指标。[4:22](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=262s)
- 数学上可写为：
  $$C = \frac{1}{n}\sum_{i=1}^{n} \sum_{j} \big(a_j^{(i)} - y_j^{(i)}\big)^2$$
  其中 $a_j^{(i)}$ 是第 $i$ 个样本输出层第 $j$ 个神经元的激活，$y_j^{(i)}$ 是目标值，$n$ 是训练样本数（平方形式为常见写法，与视频口述一致）。
- 网络本身是一个输入 784 个像素、输出 10 个数字的函数；代价函数是叠加在其上的又一层函数——输入约 13,000 个权重和偏置，输出一个表示“这组参数有多差”的数。[4:46](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=286s)
- 训练的目标就是**最小化这个代价函数**：由于对 13,000 输入的函数无法显式求解最小值，实际采用沿斜坡往下走的策略，也就是 [[梯度下降]]。[5:12–5:41](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=312s)

## 🧩 在视频/系统中的角色

出现在 **ch08 代价函数** 一章（视频系列《But what is a neural network》的学习机制部分）。它承上启下：前面各章把网络表示为函数（[[神经元与激活]]、[[分层结构]]、[[权重与偏置]]），本章引入代价函数把“网络表现好坏”量化为单一数值，为下一章 [[梯度下降]] 提供优化的目标——先定义“糟糕”，才能学会“变好”。

## 📌 执行顺序

1. 随机初始化全部权重和偏置，此时网络输出一团混乱。[3:01](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=181s)
2. 输入一个训练样本，得到输出层的实际激活值。
3. 把每个输出激活与其目标值之差取平方并求和，得到**单样本代价**。[3:51](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=231s)
4. 对数万个训练样本重复上述计算，取平均值，得到**整体代价**。[4:22](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=262s)
5. 后续（ch09）沿负梯度方向小步调整约 13,000 个参数，反复迭代使代价下降。

## ⚖️ 优点与局限

| ✅ 优点 | ⚠️ 局限 |
| --- | --- |
| 把数万样本上的网络表现压缩成一个数，为学习提供明确可优化的目标 | 它是约 13,000 个输入的复杂函数，无法像一元函数那样显式解出最小值，只能用数值方法（梯度下降）逐步逼近 |
| 平方和形式简单直观：分类自信正确时代价小、混乱时代价大 | 梯度下降只能到达某个局部最小值，起点不同落点不同，且不保证是全局最低的代价（见 [[局部最小值]]） |
| 步长与斜率成比例时，接近最小值会自动减小步子，避免越过谷底 | 以视频为准：单一代价数值本身不告诉计算机具体该改哪些参数，还需配合梯度信息 |
