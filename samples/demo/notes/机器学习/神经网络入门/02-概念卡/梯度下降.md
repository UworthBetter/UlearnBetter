# 梯度下降

> [!abstract] 一句话定义
> ==反复沿负梯度方向对约 13,000 个权重和偏置做小步调整，使代价函数收敛到局部最小值的学习算法。==

## 📌 是什么

- 别名 **Gradient Descent**。视频用「球滚下山坡」作直观比喻：代价函数画成输入空间上方的曲面，学习就是不断朝“下坡方向”迈小步（[7:22](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=442s)）。
- 多元微积分中，**梯度指向上升最快的方向**，因此取负梯度就得到下降最快的方向；梯度向量的长度还表示坡度有多陡（[7:47](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=467s)）。
- 把网络全部约 13,000 个权重和偏置排成一个巨大的列向量，负梯度就是这个超高维空间里的一个方向，指示对哪些数字做怎样的微调能让代价下降最快（[8:36](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=516s)）。
- 每个负梯度分量有两层含义：**符号**说明对应参数该调大还是调小，**相对大小**说明哪些调整“更划算”——梯度编码了各权重与偏置的相对重要性（[10:45](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=645s)）。例如二维梯度 $(3,1)$ 可读作：改动第一个变量的价值是第二个变量的 3 倍（[11:37](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=697s)）。
- 代价函数对所有训练样本取平均，最小化它意味着网络在全部样本上的整体表现变好；要让输出从“随机的 10 个数”变成我们想要的决策（[9:02](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=542s)）。

$$\vec{w} \leftarrow \vec{w} - \eta \,\nabla C$$

（以视频为准：视频未给出具体更新公式与学习率记号，此处为常见写法。）

## 🧩 在视频/系统中的角色

梯度下降主要出现在 **[[ch09 梯度下降]]** 一章，是整个系列“网络如何学习”的核心答案：所谓“网络在学习”，本质上就是在==最小化代价函数==（[9:50](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=590s)）。在体系的层级中：网络本身是 784 输入、10 输出的函数；[[代价函数]]在这之上叠加一层复杂度，把 13,000 个参数映射为一个“糟糕程度”；而代价函数的梯度又叠一层，指出哪些参数改动影响最大（[12:30](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=750s)）。梯度下降用这个梯度迭代更新参数，而高效计算梯度的算法——[[反向传播]]——正是下一章的主题，被称为“神经网络学习的心脏”（[9:26](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=566s)）。

此外，这也解释了人工神经元为何采用连续取值的激活（如 [[Sigmoid 函数]]、[[ReLU]]），而非生物神经元的二值开关：只有代价函数平滑，才可能通过小步下坡找到局部最小值（[10:17](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=617s)）。

## 📌 执行顺序

1. 用全部训练数据计算代价函数的梯度（实践中由 [[反向传播]] 高效完成）。
2. 沿**负梯度**方向确定下坡方向与坡度。
3. 对全部约 13,000 个权重和偏置做一次小步调整。
4. 重复以上过程，使代价收敛到某个[[局部最小值]]（[8:12](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=492s)、[10:17](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=617s)）。

## ⚖️ 优点与局限

| ✅ 优点 | ⚠️ 局限 |
| --- | --- |
| 梯度向量编码了每个权重和偏置的相对重要性，知道“改动哪些参数最划算”（[10:45](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=645s)） | 只能收敛到某个[[局部最小值]]（图上的“山谷”），结果取决于初始点，不保证是全局最低代价（[10:17](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=617s)） |
| 原则上存在可行的方法计算这个方向向量，不必精通多元微积分的细节也能理解算法（[7:47](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=467s)） | 对全部约 13,000 个参数、在全部训练样本上算梯度代价高昂，因此实践中引入 [[随机梯度下降]] 加速（以视频为准） |
| 概念上对 2 输入和 13,000 输入的函数是同一个基本思想，易于推广（[8:12](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=492s)） | 要求代价函数输出平滑连续，否则“小步下坡”无从谈起——这是激活函数必须连续的原因（[9:50](https://www.youtube.com/watch?v=IHZwWFHWa-w&t=590s)） |
