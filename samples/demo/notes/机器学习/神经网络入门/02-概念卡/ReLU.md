# ReLU

> [!abstract] 一句话定义
> ==取 0 与加权和 $a$ 二者中较大者的激活函数，在现代深度网络中比 Sigmoid 更容易训练。==

## 📌 是什么

- 全称 Rectified Linear Unit（修正线性单元），定义为 $\mathrm{ReLU}(a) = \max(0, a)$，其中 $a$ 是该神经元的加权和。
- 当加权和 $a$ 超过某个阈值时，输出就是 $a$ 本身（恒等函数）；不足阈值时直接输出 0，神经元“不激活”（[17:19](https://www.youtube.com/watch?v=aircAruvnKk&t=1039s)）。
- 最初的动机部分来自生物学类比：真实神经元要么被激活、要么静默，超过阈值才有输出，ReLU 是这一行为的简化版（[17:47](https://www.youtube.com/watch?v=aircAruvnKk&t=1067s)）。
- 视频中 Lisha Li 提到，早期网络普遍使用 Sigmoid 把加权和压缩到 0–1 区间，但如今很少有现代网络还在用 Sigmoid；人们转用 ReLU 后发现在非常深的网络里训练效果好得多（[17:19](https://www.youtube.com/watch?v=aircAruvnKk&t=1039s)–[18:15](https://www.youtube.com/watch?v=aircAruvnKk&t=1095s)）。

## 🧩 在视频/系统中的角色

出现在 [[ch06 结语与激活函数]]：作为对 [[Sigmoid 函数]] 的替代方案被提出，说明激活函数的选择会直接影响深度网络能否顺利训练。在视频讲的体系里，它和 Sigmoid 一样位于神经元内部——把 [[权重与偏置]] 算出的加权和转换成新的激活值，决定该神经元在多大程度上“点亮”下一层。

## ⚖️ 优点与局限

| ✅ 优点 | ⚠️ 局限 |
| --- | --- |
| 在极深的神经网络中比 Sigmoid 更容易训练，实际效果很好 | 并非从理论出发的最优设计，而是“试出来好用”的简化（以视频为准） |
| 与真实神经元“超过阈值才激活”的行为有类比，概念上直观 | 当加权和小于 0 时输出恒为 0，具体的其他缺点视频未展开（以视频为准） |
