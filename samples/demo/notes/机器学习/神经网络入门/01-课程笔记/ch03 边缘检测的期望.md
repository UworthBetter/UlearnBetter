# ch03 边缘检测的期望

> [!info] 视频位置
> [8:38 Edge detection example](https://www.youtube.com/watch?v=aircAruvnKk&t=518s)

## 🎯 本章目标

理解对分层结构的期望：像素组合成边缘、边缘组合成图案（如圆环）、图案再拼出数字的逐级抽象，以及第二层神经元如何通过权重与偏置去“检测一条边”。

## 逐级抽象的期望

视频用识别手写数字的例子说明为什么“分层”是合理的：

1. **第一层看像素**：输入层就是一张图片的像素亮度值。
2. **第二层检测边缘**：希望某个特定神经元能判断“图片的这个区域里有没有一条边”（[8:39](https://www.youtube.com/watch?v=aircAruvnKk&t=519s)）。
3. **第三层组合图案**：几条边缘可以组成更大的组件，比如一个小圆环（loop）（[9:03](https://www.youtube.com/watch?v=aircAruvnKk&t=543s)）。
4. **输出层拼出数字**：圆环等组件再组合，最终形成对"9"、"8"这类数字的判断。

这正是对分层结构的核心期望——每一层都在上一层的输出之上做更高一级的抽象（与 [[ch02 分层结构]] 呼应）。

## 用权重调出“边缘检测器”

要让一个神经元检测某区域的边缘，关键在于如何设置参数——视频称之为“旋钮和拨盘”（dials and knobs）：

- 给神经元与第一层每个像素的连接各分配一个 **权重（weight）**，就是普通的数字（[9:03](https://www.youtube.com/watch?v=aircAruvnKk&t=543s)）。
- 计算第一层所有激活值按权重的加权和（weighted sum）。
- 权重可以想成一个绿色/红色像素组成的小网格：**绿色 = 正权重，红色 = 负权重，亮度粗略表示数值大小**（[9:31](https://www.youtube.com/watch?v=aircAruvnKk&t=571s)）。

构造一个边缘检测器的具体做法：

| 设置 | 目的 |
| --- | --- |
| 关心区域外的像素权重几乎全设为 0 | 加权和就只累加关心区域内的像素值 |
| 关心区域内设正权重 | 区域越亮，和越大 |
| 周围一圈像素设负权重 | 只有“中间亮、四周暗”时和最大——正是边缘的特征 |

（[9:59](https://www.youtube.com/watch?v=aircAruvnKk&t=599s)）

## 用 Sigmoid 压缩 + 偏置定门槛

加加权和你可能得到任意实数，但网络需要激活值落在 0 到 1 之间，于是：

1. 把加权和学习一个 **Sigmoid 函数**（logistic curve）：很负的输入趋近 0，正输入趋近 1，在 0 附近平缓上升（[10:28](https://www.youtube.com/watch?v=aircAruvnKk&t=628s)）。
2. 神经元的激活值就变成“加权和学习有多正”的度量（[10:52](https://www.youtube.com/watch?v=aircAruvnKk&t=652s)）。
3. 若希望加权和超过某个门槛（比如 10）才激活，就在求和后再加上一个数（如 -10）再过 Sigmoid——这个数就是 **偏置（bias）**（[11:20](https://www.youtube.com/watch?v=aircAruvnKk&t=680s)）。

> [!quote] 视频原话
> 权重告诉你这个第二层神经元在检测什么像素图案，偏置则告诉你加权和要多高神经元才会真正被激活。（大意，[11:20](https://www.youtube.com/watch?v=aircAruvnKk&t=680s)，以视频为准）
