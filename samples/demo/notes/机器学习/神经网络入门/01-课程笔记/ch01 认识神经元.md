# ch01 认识神经元

## 🎯 本章目标
理解神经元就是持有 0–1 之间一个数值（激活）的基本单元，并明确手写数字识别这一任务的设定。

## 识别一个"3"有多难

视频开篇用一张 28×28 像素、写得很潦草的数字 3 引入：人脑毫不费力就能认出它是 3，而且[不同的"3"写法各异、像素值完全不同](https://www.youtube.com/watch?v=aircAruvnKk&t=4s)，眼睛里实际被激发的感光细胞也各不相同，但视觉皮层仍把它们归结为同一个"概念"（[0:28](https://www.youtube.com/watch?v=aircAruvnKk&t=28s)）。

可是一旦让你坐下写一个程序：输入 28×28 的像素网格，输出 0–10 之间的一个数字表示它认为这是哪个数字——任务就从“简单得可笑”变成“难得吓人”（[0:54](https://www.youtube.com/watch?v=aircAruvnKk&t=54s)）。这正是引入机器学习和神经网络的理由。

## 任务设定与本系列范围

- **目标**：搭建一个能学会识别手写数字的神经网络——这是该领域的经典入门例子（[1:43](https://www.youtube.com/watch?v=aircAruvnKk&t=103s)）。
- **范围**：神经网络有很多变体，近年研究热潮也多在变体上；本系列只讲最简单、最朴素的"vanilla"形式——它是理解一切现代变体的必要前提，但复杂度也已经足够烧脑（[2:07](https://www.youtube.com/watch?v=aircAruvnKk&t=127s)）。
- **分工**：本视频只讲**结构**，下一个视频讲**学习**（[1:18](https://www.youtube.com/watch?v=aircAruvnKk&t=78s)）。
- 即使在最简单的形式下，网络也能学会识别手写数字，但同时也会看到它在某些期待上的不足（[2:29](https://www.youtube.com/watch?v=aircAruvnKk&t=149s)）。

## 神经元是什么：一个装数的容器

> [!quote]
> "When I say neuron all I want you to think about is a thing that holds a number, specifically a number between 0 and 1."（说到神经元，你只需想：一个装着数的容器，具体说是 0 到 1 之间的数。）[2:42](https://www.youtube.com/watch?v=aircAruvnKk&t=162s)

理解神经元只需以下几步（[2:42–3:25](https://www.youtube.com/watch?v=aircAruvnKk&t=162s)）：

1. 神经元 = 持有**一个数**的单元，这个数称为它的 **激活（activation）**。
2. 激活的取值范围限定在 **0 到 1** 之间。
3. 输入层由 784 个神经元组成，对应输入图像的 28×28 = 784 个像素。
4. 每个神经元的激活代表对应像素的灰度值：**0 表示纯黑，1 表示纯白**。
5. 直观画面：激活数值越接近 1，神经元越"亮"。
