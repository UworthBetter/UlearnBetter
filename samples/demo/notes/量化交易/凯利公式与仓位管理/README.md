# 📓 凯利公式与仓位管理 · 学习笔记库

基于 YouTube 视频 **《KELLY CRITERION | Ed Thorp | Optimal Position Sizing For Stock Trading》**（Financial Wisdom，8:13）整理的 Obsidian 笔记库。

> [!important] 数据来源声明
> 本库基于 YouTube 官方元数据与官方章节 + 平台自动字幕（video_ingest.py 抓取，2026-11-07 核对）整理。
> 笔记已整理为中文；由模型 glm-5.3-flash 按本技能模板生成，字幕为平台自动识别，细节以视频为准。
> 如发现笔记与视频不符，以视频描述栏与官方章节为准。

> [!tip] 如何打开本库
> 1. 打开 Obsidian → 左下角 **管理仓库（Manage vaults）**
> 2. **打开文件夹作为仓库（Open folder as vault）** → 选择本文件夹
> 3. 从 [[00-Home]] 开始

## 目录结构

| 文件夹/文件 | 用途 |
| --- | --- |
| `README.md` | 使用说明与数据来源声明（本页） |
| `00-Home.md` | 学习主页（MOC）：全景图、学习路线、概念卡索引 |
| `01-课程笔记/` | 按官方章节归组的章节笔记，带时间戳跳转链接 |
| `02-概念卡/` | 原子概念卡，一页一卡，互相 wikilink |
| `03-实操清单/` | 可打勾执行的清单：凯利仓位计算、交易表现记录与调仓 |
| `90-资源/` | 视频信息与章节时间戳、术语表 |
| `Templates/` | 概念卡模板，供日后自行添加新卡 |

## 使用建议

- 第一遍：按 [[00-Home]] 学习路线读章节笔记，配合时间戳看视频
- 第二遍：脱离视频，用概念卡自测
- 动手：跟 [[凯利仓位计算清单]] 与 [[交易表现记录与调仓清单]] 执行
