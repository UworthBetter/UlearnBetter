# 交易优势

> [!abstract] 一句话定义
> ==自己估计的胜率相对市场赔率隐含概率多出的部分；算出的凯利值为负即无优势、不应下注。==

## 📌 是什么

- 凯利公式本质上计算的是“你对该事件的**感知优势（perceived edge）**”，并据此调整下注/仓位大小（[0:46](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=46s)）。
- 优势来自“自己分析的胜率”与“市场赔率隐含概率”的差：如拳击例中市场赔率 1.9 隐含 52.6% 胜率，而自己分析得出 55%，多出的部分就是优势（[1:33](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=93s)）。
- 若自己的概率与市场赔率隐含概率相同，凯利公式算出**负值**——意味着没有优势，不应下注（[3:20](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=200s)）。
- 自估概率越高（如 60%），优势越大，凯利公式会建议更高的仓位以利用这一优势（[3:20](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=200s)）。
- 数学上，优势体现在凯利公式分子 $bp - q$ 中（$b$ 为盈亏比、$p$ 为胜率、$q$ 为败率）：只有 $bp > q$ 时结果才为正。

$$
f = \frac{bp - q}{b}
$$

## 🧩 在视频/系统中的角色

交易优势出现在 [[ch01 引言与凯利公式原理]] 与 [[ch02 凯利公式手算实例]]。它是整个凯利公式的**前提条件**：公式四个输入（本金、盈亏比、胜率、败率）最终汇聚成对“优势”的量化，优势决定最优仓位是否存在以及有多大。没有正优势，一切仓位计算都没有意义。

## 📌 执行顺序

1. 获取市场赔率，换算出市场隐含的胜率（如赔率 1.9 → 隐含约 52.6%）。
2. 通过自己的独立分析，估计更真实的胜率。
3. 将盈亏比、自估胜率、败率代入凯利公式计算。
4. 若结果为负 → 无优势，不下注；若为正 → 结果即建议仓位比例。
5. （可选）用分数凯利折减建议仓位，以应对概率估计的不确定性。

## ⚖️ 优点与局限

| ✅ 优点 | ⚠️ 局限 |
| --- | --- |
| 正优势才下注，天然过滤掉无价值的交易机会 | 自估胜率依赖主观分析，估计偏差会导致仓位失真 |
| 优势越大，建议仓位越高，能充分利用超额胜率 | 股市变量众多、价格随机性强，难以像二十一点那样获得准确的真实概率（以视频为准） |
