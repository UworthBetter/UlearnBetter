# 分数凯利

> [!abstract] 一句话定义
> ==只取凯利公式建议仓位的一定比例（作者用 33%）建仓，以应对股市变量众多、概率不确定的风险。==

## 📌 是什么

- 全凯利公式算出的仓位往往过大：作者以 $20,000 账户、59% 胜率、盈亏比 4.04 计算，全凯利建议仓位高达 49%（$9,800），相对账户余额显得过大，因此作者和许多人采用分数凯利（[4:45](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=285s)）。
- 做法：只取凯利建议仓位的一个比例建仓，作者个人使用 33%，上例中仓位即为 $3,266（[4:45](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=285s)）。
- 分数凯利算出的是**仓位规模，不等于风险额**：按典型 10% 止损，$3,266 仓位的风险约 $326，折合账户权益的 1.63%（[5:06](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=306s)）。
- 适用原因：凯利公式本质上基于固定变量、真实概率可知的事件（如二十一点），而股市价格波动随机、输入变量多变，故若要用凯利，建议采用分数凯利（[7:14](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=434s)）。
- 在全凯利曲线上，分数凯利（如 33%）位于峰值的左侧，属于更保守的一侧：收益略低，但波动也显著更小（[6:53](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=413s)）。

## 🧩 在视频/系统中的角色

分数凯利出现在 **ch03 分数凯利与动态调仓**（首次提出并给出 33% 的实际计算示例）与 **ch04 全凯利曲线与适用边界**（解释其在凯利曲线上的位置与适用边界）。它是作者实际采用的[[仓位与风险换算|仓位管理]]工具——作者称其为“我最偏好的仓位管理工具”，因为它能随交易表现（[[交易优势|交易优势]]）变化调整风险：趋势市中优势提升、仓位放大，震荡市中优势下降、仓位收缩。

## 📌 执行顺序

1. 用[[凯利公式]]按胜率、败率与盈亏比算出全凯利建议仓位（如上例的 49% / $9,800）。
2. 取建议仓位的一个固定比例（作者用 33%），得到实际仓位规模 $3,266。
3. 用止损比例把仓位换算为实际风险额（10% 止损 → 约 $326，占账户 1.63%）。
4. 持续记录交易表现，更新胜率与盈亏比等输入（如胜率降到 50%、盈亏比 2，凯利重新算出 25% / $5,000，再取 33%）。
5. 随市场状态自动伸缩仓位：趋势市放大、震荡市收缩。

## ⚖️ 优点与局限

| ✅ 优点 | ⚠️ 局限 |
| --- | --- |
| 比全凯利更保守，位于凯利曲线峰值左侧：波动更小、回撤风险更低（以视频为准） | 收益也低于全凯利峰值仓位——用收益换稳健（以视频为准） |
| 能反映交易表现并相应调整风险，是作者最偏好的仓位管理工具（[7:34](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=454s)） | 凯利输入（胜率、盈亏比）在股市中只能近似估计，比例再保守也依赖输入质量 |
| 削弱了“股市变量众多、概率不确定”带来的估算误差影响（[7:14](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=434s)） | 固定 33% 是作者的个人选择，具体比例应以视频为准并结合自身风险承受力 |
