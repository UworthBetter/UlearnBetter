# 最优仓位

> [!abstract] 一句话定义
> ==凯利公式输出的应投入金额，应随四个输入变量变化，而非预先固定的策略参数。==

## 📌 是什么

- 最优仓位（Optimal Position Size）是凯利公式算出的结果：给定本金、赔率/盈亏比、胜率与败率，公式输出当前应投入的比例或金额。
- 它不是固定参数，而是随输入变量动态变化的输出——若自己估计的概率与市场隐含概率相同，计算结果为负，意味着没有优势、不应下注（[3:20](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=200s)）；若胜率更高（如 60%），公式会建议加大投入（[3:20](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=200s)）。
- 博彩例子：赔率 1.9、自估胜率 55% 时，凯利值 5%，对应 $1,000 资金的 optimal stake 为 $50（[2:59](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=179s)）。
- 交易例子：胜率 59%、每 $1 风险盈利 4.04 时，凯利值约 49%，对应 $20,000 资金的 optimum position size 为 $9,800（[4:24](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=264s)）。因仓位过大，作者实际使用分数凯利（33%），实际仓位 $3,266。
- 注意：凯利输出的是**仓位大小**而非风险额；按典型 10% 止损换算，$3,266 仓位的实际风险约 $326，占权益 1.63%（[5:06](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=306s)）。

公式形式（以视频实例为准）：

$$\text{凯利值} = \frac{B \times p - q}{B}$$

其中 $B$ 为盈亏比（每 $1 风险的盈利）、$p$ 为胜率、$q$ 为败率。

## 🧩 在视频/系统中的角色

出现在 **ch02 凯利公式手算实例** 与 **ch03 分数凯利与动态调仓**。它是凯利公式整个计算流程的最终产出：把「交易优势」变现为具体金额的桥梁。视频强调它应是随交易表现波动而更新的动态值（凯利分数随策略表现起伏而变化，[6:10](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=370s)），而非一次性设定的固定参数；实际执行时再经分数凯利打折使用。

## 📌 执行顺序

1. 确定本金（如 $1,000 资金 / $20,000 权益）。
2. 用市场赔率推算隐含概率，再通过自己的分析得出更接近真实的胜率与败率。
3. 确定盈亏比（如每 $1 风险的预期盈利 4.04）。
4. 代入凯利公式计算比例（如 5% / 49%）。
5. 用比例乘以本金得到最优仓位金额。
6. 结合分数凯利与止损比例，换算出实际仓位与每笔风险。

## ⚖️ 优点与局限

| ✅ 优点 | ⚠️ 局限 |
| --- | --- |
| 把优势大小量化为具体投入金额，胜率越高建议仓位越大，逻辑自洽（[3:20](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=200s)） | 股市价格随机、输入变量不稳定，不如二十一点等固定变量事件可得到真值（[5:27](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=327s)） |
| 有计算器和电子表格可自动计算，不必被数字吓退（[2:59](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=179s)） | 全凯利建议的仓位可能过大（如 49%），直接照用资金集中度过高，需分数凯利打折（[4:45](https://www.youtube.com/watch?v=THYLv5_0Vm8&t=285s)） |
| 输出为仓位大小而非风险额，需再用止损比例换算实际风险 | 胜率、盈亏比是估计值，估计偏差会直接放大或缩小仓位；具体数值以视频为准 |
