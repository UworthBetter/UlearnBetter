# 🛠️ 交易表现记录与调仓清单

> [!info] 用途
> 凯利公式的四个输入（账户权益、盈亏比、胜率、败率）在股市中会随行情波动，需要定期记录交易表现、更新输入、按 [[分数凯利]] 重新计算仓位。参考视频第 5:27–6:33 段「保持绩效追踪并相应调整输入」。

## 1️⃣ 定期记录交易表现（如每月一次）
- [ ] 导出/整理本周期内所有已平仓交易（作者使用交易分析软件如 Edgewonk，也可用自带表格；验证方式：交易笔数与券商对账单一致）
- [ ] 统计胜率（win rate）= 盈利笔数 ÷ 总笔数（验证方式：胜率在 0–100% 之间，样本不足时暂不更新，见避坑）
- [ ] 统计每元风险的利润（profit on risk）= 平均每笔盈利额 ÷ 平均每笔风险额（验证方式：作者的长期数据为胜率 59%、每元风险利润约 4.04——作者当时测得，勿照搬结论，以自己的实际记录为准）
- [ ] 与上一周期对比，判断优势（[[交易优势]]）是扩大还是缩小（验证方式：趋势行情中优势通常上升，震荡行情中下降——作者经验，以视频为准）

## 2️⃣ 更新凯利公式输入并重算仓位
- [ ] 确认当前账户权益余额（验证方式：以券商账户实际净值为准）
- [ ] 用新胜率与每元风险利润代入凯利公式：`K = (盈亏比 × 胜率 − 败率) ÷ 盈亏比`（验证方式：结果为正说明有优势；为负说明无优势，不应开仓——参考 [[ch02 凯利公式手算实例]]）
- [ ] 全凯利结果乘以自己的分数比例（作者用 33%）得到实际仓位大小（验证方式：可对照 [[凯利仓位计算清单]] 复算一遍）
- [ ] 把仓位大小换算成风险金额：仓位 × 平均止损比例 ≈ 单笔风险；再除以权益得到风险占比（验证方式：作者示例中 33% 分数仓位 + 10% 止损 ≈ 权益风险的 1.63%；表现下滑至胜率 50%、利润 $2/$1 风险时降至约 0.83%——作者当时测得，勿照搬结论）

## 3️⃣ 执行调仓并复核
- [ ] 将新仓位与当前实际持仓对比（验证方式：持仓市值 vs 新仓位大小，差异超出容差即需加减仓）
- [ ] 若优势下降导致新仓位更小，逐步减仓至目标水平（验证方式：减仓后单笔风险占权益比例回落到新目标）
- [ ] 若优势上升，按新分数仓位适度加仓，但始终留在 [[全凯利曲线]] 左侧的保守区域（验证方式：实际仓位 ≤ 全凯利仓位）
- [ ] 记录本次调整的理由与日期，便于下周期复盘（验证方式：笔记/表格中有留痕）

> [!warning] 避坑
> - 凯利公式基于固定变量与真实概率（如 21 点牌堆）；股市价格随机、输入多变，==不要直接用全凯利仓位==，视频建议采用分数凯利（作者用 33%）
> - 凯利分数给出的是仓位大小（position size），不是风险额；实际风险还要乘以止损比例再换算
> - 若自己估计的胜率不高于市场隐含概率，凯利公式结果为负——意味着没有优势，此时不该下注
> - 短期样本不足以反映真实胜率/盈亏比，样本太少时不要贸然大幅调仓
