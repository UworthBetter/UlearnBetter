## 使用

运行 `concept-graph` 的 `npm ci`、`npm run dev`，页面右下角出现学习伙伴。
页面上平时只有这一只桌宠，没有常驻输入栏。点击角色（或按 `/`）才在它上方
弹出对话面板，场景、历史、输入栏和连接状态都在面板内；再点角色、点面板外或
按 `Esc` 收起，`Esc` 会把焦点还给角色。面板打开时角色停在默认位置，拖动只在
面板关闭时可用；移动至少 7 px 才算拖动，拖动不会发送问题或打开面板。

提交问题后面板保持打开，回答直接出现在面板历史里。面板关闭时，最新回答和
提示卡浮在角色上方，与角色保持 6 px 间距；点击卡片或再次点角色可重新打开面板。
全局的底部安全区变量 `--ub-agent-bar-height` 固定为 `84px`（写在 `shell.css`），
助手不再用 JS 写它，潜航时间轴等浮层继续读取这个默认值。

关闭面板时右键或 Shift+F10 打开设置：暂停/恢复动画、预览 13 种动作、
回到右下角。预览结束自动恢复当前助手状态；系统减少动态效果启用时显示
静态站姿。动画加载失败回退站姿；站姿也失败时仍保留可点击的文字入口。
手机上点角色后面板全屏并覆盖导航，关闭后恢复角色；窄屏显示回答或提示卡时
卡片从角色上方展开，角色仍在右下角。短屏使用更紧凑的布局。

## 状态来源

| 应用事件 | 角色反馈 |
| --- | --- |
| 等待模型首段回复 | 思考 |
| 正在流式回复或执行助手工具 | 处理 |
| 完成回复且历史或回答卡可见 | 完成动作一轮，回答视为已读 |
| 收起回答卡且历史关闭期间完成回复 | 新消息动作一轮，未读标记保留到查看 |
| 请求/连接失败 | 错误 |
| 停止回复 | 恢复待机，不标记成功 |

角色气泡显示当前页面场景；每条回答仍使用发送当时的场景快照。
切换今天、全景、资料、星图或概念图不会重建助手或丢失会话。
编码、调试、喝水等动作可手动预览，未接入操作系统监测或健康定时器。
动作预览不代表任务真实发生；演示模式继续明确标注未调用真实模型。
