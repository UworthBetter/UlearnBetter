## 使用

运行 `concept-graph` 的 `npm ci`、`npm run dev`，页面右下角出现学习伙伴。
页面上平时只有这一只桌宠，没有常驻输入栏。点击角色（或按 `/`）才在它上方
弹出对话面板，场景、历史、输入栏和连接状态都在面板内；再点角色、点面板外或
按 `Esc` 收起，`Esc` 会把焦点还给角色。角色随时能拖，面板开着也能拖；移动至少
7 px 才算拖动，拖动不会发送问题，也不会误触开合。

面板和浮出的卡片都挂在角色上：把角色拖到别处，面板跟着走，在角色正上方居中，
和角色留 8 px 间距；贴到屏幕左右边缘时自动夹住，不会溢出。角色拖到屏幕上方
放不下时，面板自动翻到角色下方展开，高度按可用空间收缩到 200–620 px。位置由
`pet-state.ts` 的 `clampPetPosition` 和 `placeAssistantPanel` 计算，都是纯函数、
有单测；窗口尺寸变化会重新夹一次，角色不会跑到屏幕外。

提交问题后面板保持打开，回答直接出现在面板历史里。面板关闭时，最新回答和
提示卡浮在角色旁边（默认上方，角色贴近顶部时改到下方），与角色保持 8 px 间距；
点击卡片或再次点角色可重新打开面板。
全局的底部安全区变量 `--ub-agent-bar-height` 固定为 `84px`（写在 `shell.css`），
助手不再用 JS 写它，潜航时间轴等浮层继续读取这个默认值。

右键或 Shift+F10 随时打开设置，面板开着也行：暂停/恢复动画、预览 13 种动作、
回到右下角。菜单贴着角色出现，角色在屏幕下半部时向上展开，不会越出视口。
预览结束自动恢复当前助手状态；系统减少动态效果启用时显示
静态站姿。动画加载失败回退站姿；站姿也失败时仍保留可点击的文字入口。
手机上点角色后面板全屏并覆盖导航，关闭后恢复角色；窄屏下角色仍是常驻入口，
面板固定在顶部全屏展开，不跟随拖动。短屏（可用高度不足 620 px）时面板自动
收缩高度，不再隐藏角色。

## 状态来源

| 应用事件 | 角色反馈 |
| --- | --- |
| 等待模型首段回复 | 思考 |
| 正在流式回复或执行助手工具 | 处理 |
| 完成回复且历史或回答卡可见 | 完成动作一轮，回答视为已读 |
| 收起回答卡且历史关闭期间完成回复 | 新消息动作一轮，未读标记保留到查看 |
| 请求/连接失败 | 错误 |
| 停止回复 | 恢复待机，不标记成功 |

角色气泡显示当前页面场景；每条回答仍使用发送当时的场景快照。
切换今天、全景、资料、星图或概念图不会重建助手或丢失会话。
编码、调试、喝水等动作可手动预览，未接入操作系统监测或健康定时器。
动作预览不代表任务真实发生；演示模式继续明确标注未调用真实模型。
