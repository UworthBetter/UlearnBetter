# 学习助手桌宠适配

分支：`codex/pet-assistant`。本次在独立 worktree 完成，基于当前 main，
修改范围为助手 UI、新增运行时角色资源、助手测试及 CI 测试入口。
公共场景契约和后端接口不变。

## 使用

运行 `concept-graph` 的 `npm ci`、`npm run dev`，页面右下角出现学习伙伴。
点击打开原有学习助手；面板关闭时，移动至少 7 px 可拖动角色，拖动不会发送
问题或打开面板。打开面板后，角色回到右下角；关闭后恢复拖动位置。
调整浏览器尺寸时，角色会被限制在视口内。位置与暂停偏好只保留在当前页面。

关闭面板时右键或 Shift+F10 打开设置：暂停/恢复动画、预览 13 种动作、
回到右下角。预览结束自动恢复当前助手状态；系统减少动态效果启用时显示
静态站姿。动画加载失败回退站姿；站姿也失败时仍保留可点击的文字入口。
手机上助手全屏打开，关闭后恢复角色；短屏使用更紧凑的布局。

## 状态来源

| 应用事件 | 角色反馈 |
| --- | --- |
| 等待模型首段回复 | 思考 |
| 正在流式回复或执行助手工具 | 处理 |
| 完成回复且面板打开 | 完成动作一轮 |
| 面板关闭期间完成回复 | 新消息动作一轮，未读标记保留到打开 |
| 请求/连接失败 | 错误 |
| 停止回复 | 恢复待机，不标记成功 |

角色气泡显示当前页面场景；每条回答仍使用发送当时的场景快照。
切换星图/概念图不会重建助手或丢失会话。
编码、调试、喝水等动作可手动预览，未接入操作系统监测或健康定时器。
动作预览不代表任务真实发生；演示模式继续明确标注未调用真实模型。

## 资源与范围

按 build-photo-desktop-pet 技能复用用户指定项目的现有 13 个透明 APNG 和
静态站姿，继承源项目已确认的简体中文/zh-CN。没有生成新图片，也没有向
图像服务发送照片。资源共约 11.9 MB，浏览器按当前动作请求，不预加载全套。
只复制运行时资源与动画制作契约；未引入照片、配置、安装包或 Tauri 依赖。
本交付是学习应用内适配，没有创建新的桌面安装包或增加系统通知权限。
