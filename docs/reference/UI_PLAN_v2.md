### v2 改了什么

负责人对 v1 的反馈：「不错的，但是没有个人学习统计，没有智能体整理学习资料，归类，给出个人学习全景图」。

| 反馈 | v2 的做法 | 页面数量 |
| --- | --- | --- |
| 没有个人学习统计 | 「今天」顶部加一条**统计条**（近 9 天热力、本周时长、连续天数、回忆正确率、已学概念）。点开是**学习统计层**：时长、掌握、正确率、热力图、各目标进度曲线 | 不加页面，是「今天」上的一层 |
| 没有智能体整理学习资料、归类 | 新增**资料**视图：丢进来的每一份东西、智能体识别成什么、归到哪个目标、抽出哪些概念、整理到哪一步（整理中 / 待确认 / 已整理），并接入调整归类。v1 的「笔记」修正抽屉并入这里 | 顶部「笔记」换成「资料」，总数不变 |

顶部仍然只有三个词：**今天 · 全景 · 资料**。

## 0. 一句话

**三个视图，一根输入栏。**
- 「今天」：该学什么，学得怎么样。
- 「全景」：我学的东西整体长什么样。
- 「资料」：我丢进来的东西被整理成了什么。

底部的 Agent 栏是唯一入口：丢材料、提问、确认整理结果都从这里走。统计、调整归类、助手回答都是浮在当前视图上的一层，不单独成页。

| 负责人要求 | 方案里的落点 |
| --- | --- |
| 极简 | 3 个视图。没有侧栏、设置页、聊天页、单独的统计页 |
| Agent 输入是唯一入口，固定在底部 | 每个视图底部都是同一根 Agent 栏。全景图有右侧摘要栏，Agent 栏在左侧星图区里居中，不压摘要栏 |
| 不做以聊天框为中心的布局 | 助手的话以**卡片**形式出现在栏上方，一次一张 |
| 用户丢进来，agent 整理，结果可调但不强制 | 资料视图把整理过程摊开给人看；高置信的归类自动接受，只把低置信的放进「待确认」 |
| 星图 = agent 整理结果的可视化 | 全景图按目标分区，主题内按笔记里的分组聚星 |
| 总控台 = 目标、进度、今日学习 | 「今天」：统计条 + 今日卡 + 目标卡 + 智能体整理卡 |
| 助手 = 答疑 + 「我已经帮你归类好了，要调整吗？」 | 同一根 Agent 栏，两种卡：提示卡（agent 主动说）和回答卡（你问它答） |
| 笔记菜单 = 修正层 | 并入资料视图的详情区：改归属、改名、隐藏、置顶重要性都在这里，改的是「你的决定」，不改原笔记 |
| 个人学习统计（v2） | 统计条 + 统计层 |
| 智能体整理资料、归类（v2） | 资料视图 |
| 个人学习全景图（v2） | 全景视图 |
| 保留星图潜航的视觉 | token 原样沿用 |

## 1. 信息架构

### 1.1 结构

```text
              ┌────────────── 顶部（极简）──────────────┐
              │ 品牌  [示例数据]         今天 · 全景 · 资料(•) │
              └──────────────────────────────────────────┘
 视图（三个）                                    覆盖层（Esc 关闭，回到原处）
 ┌─────────────┐ 点统计条                      ┌──────────────────────┐
 │ 今天         │ ───────────────────────────▶ │ 学习统计              │
 │ （总控台）    │                              ├──────────────────────┤
 └──┬───────┬──┘ 提示卡「看看」/ 待确认        │ 调整归类（提议卡组）    │
    │       │ ───────────────────────────────▶ ├──────────────────────┤
    │       │ 智能体整理卡                      │ 回答卡（助手回答）      │◀─ Agent 栏提问
    │       ▼                                  └──────────────────────┘
    │  ┌─────────────┐  详情「在全景中看」        ▲
    │  │ 资料         │ ───────────┐               │ 全景右栏「待确认的关联」
    │  │ 列表 + 详情   │            ▼               │
    │  └─────────────┘   ┌─────────────────────────┴──┐
    │ 目标卡 / 今日卡      │ 全景（缩放：全景 → 目标）      │
    └───────────────────▶ │   └ 潜航：一个主题（现有页）     │
                          │       └ 聚焦一颗星：主卡 + 环绕卡 │
                          │       └ 离开时：离星回忆         │
                          └────────────────────────────┘
 ═══════════════ 底部 Agent 栏（每个视图都在）═══════════════
```

- **三个视图**：今天、全景、资料。
  - 全景有四级缩放（全景 → 目标 → 主题 → 概念）。主题和概念两级就是现有的星图潜航，不算新页面。
- **三个覆盖层**：学习统计、调整归类、回答卡。都浮在当前视图上，关掉回到原处。
- **一根栏**：Agent 栏。
- **首次使用**是「今天」的空状态（§4）。

为什么统计不单独成页：统计回答的是「我学得怎么样」，人一般在「今天」开始学之前顺手看一眼。所以它的入口放在「今天」顶部，平时只露一条，点开才展开。全景回答「整体长什么样」，资料回答「东西被整理成了什么」。三件事分开，每屏只回答一个问题。

| 路由 | 内容 | 与 main 的关系 |
| --- | --- | --- |
| `#/` 或 `#/today` | 今天 | 取代旧的 `#/` 演示概念图（POSITIONING §7 第 5 条，等负责人拍板） |

助手现有的导航工具（`learning-tools.ts`）可以映射到这些路由，例如「打开资料」「看全景」「我这周学了多少」→ 统计层。

## 2. 各视图与覆盖层

### 2.1 今天（总控台）

**用途**：一打开就知道今天学什么、为什么学、整体学得怎么样，以及 agent 最近整理了什么。

```text
┌──────────────────────────────────────────────────────────────────────┐
│ ULEARNBETTER [示例数据]                                今天 · 全景 · 资料• │
│ TODAY · 11月7日                    ┌─ 统计条 ───────────────────────────┐ │
│ 今天学 4 件事，约 28 分钟            │近9天▪▪▫▪▪▪▪▪▫ 3.3h 5天 72% 18/36 统计→│ │
│ 排序：到期复习 → 路线下一颗 → 实操    └────────────────────────────────────┘ │
│ ┌复习────┐ ┌新学────┐ ┌实操────┐ ┌新学────┐   ← 今日卡（≤5，写为什么）       │
│ │抵扣价   │ │关键性波动│ │观察清单 │ │前视偏差 │                             │
│ └────────┘ └────────┘ └────────┘ └────────┘                             │
│ ┌目标卡：量化交易──┐ ┌目标卡：AI 工具──┐ ┌智能体整理─────── 全部 5 份→┐       │
│ │迷你星图 36·18·11│ │迷你星图 19·8·5 │ │▶ 趨勢轉折…   整理中·抽概念   │       │
│ │进度条 · 主题列表 │ │               │ │✎ 均线拐头前… 待确认·挂到抵扣价？│      │
│ └────────────────┘ └───────────────┘ │▤ AI量化…     待确认·两个目标？ │       │
│                                      │▤ 趋势交易…   已整理·12 颗星    │       │
│                                      └──────────────────────────────┘       │
│        ┌ 提示卡：我已经帮你归类好了…要调整吗？ [没问题] [看看] ┐                │
│        ╞═ ● 丢链接、笔记文件夹，或问我任何事…  [今天] [＋] [↑] ═╡                │
└──────────────────────────────────────────────────────────────────────┘
```

- **统计条（v2 新增）**：放在标题右侧，只放 5 个读数。
  - 近 9 天热力：每格一天，亮度表示学习分钟。
  - 本周学习时长、连续学习天数、回忆正确率、已学概念 / 总数。
  - 整条可点，点开学习统计层（§2.2）。数字都由学习痕迹算出，不调用模型。
- **今日卡**：同 v1。类型、概念、主题、时长、**为什么**、证据时间戳，点击直接潜航。「为什么」只能引用 TodayPlan 的 `why`，排序规则写在标题下面。
- **目标卡**：同 v1。迷你星图、意图、颗星 / 已学 / 已回忆、进度条、主题列表（待确认的主题带虚线标签）。点击打开全景。
- **智能体整理卡（v2，取代 v1 的「最近痕迹」）**：最近 4 份资料，每条是图标 + 标题 + 当前状态。
  - 状态写成人话：「整理中 · 正在抽取概念」「待确认 · 挂到『抵扣价』？」「已整理 · 12 颗星 → 量化交易」。
  - 点击进入资料视图。
  - v1 的学习痕迹列表移到统计层。

**用途**：回答「我学得怎么样」。只是一层，从统计条点开，Esc 回到「今天」。

│ │4.8 小时│ │18 / 36 │ │3     │ │72%      │ │5 天    │                    │
│ ┌每天学习分钟────┐ ┌各目标的进度（累计回忆过的概念数）──── ─量化 ─AI┐     │
│ │ 5 周热力图       │ │  两条线，单一 y 轴，终点直接标数字                │     │
│ │ 虚线格=还没开始   │ │  悬停一天：两个目标的累计 + 当天分钟             │     │
│ └────────────────┘ └───────────────────────────────────────────┘     │
│ ┌回忆正确率·按主题──┐ ┌最容易忘的──────┐ ┌最近的学习痕迹──────┐           │
│ │ 三条横条 + n/总数  │ │抵扣价 忘了·今天到期│ │置顶、勾选、提问、回忆│          │

```

| 负责人点名的统计 | 呈现 | 数据来源 |
| --- | --- | --- |
| 学习时长 | 读数（总 + 本周）+ 每天分钟热力图 | LearningEvent 的停留时长（需要记录进入、离开星的时间） |
| 学过 / 掌握的概念 | 读数：已学 18/36，其中回忆过 11；已掌握 3 | MasteryState |
| 回忆正确率 | 读数（13/18 次）+ 按主题横条 | 离星回忆事件 |
| 连续天数 / 热力图 | 读数 + 5 周热力图；开始使用前的日子用虚线格，不当作「没学」 | 每日学习分钟 |
| 各目标随时间的进度 | 折线：各目标累计「回忆过」的概念数 | MasteryState 的历史 |

图表规则：
- 两个目标两条线，共用一个 y 轴。不做双轴。
- 终点直接标「量化交易 11」，同时有图例。
- 颜色已用 dataviz 校验脚本在深色底（`#13224f`）上验证过：量化交易 `#c4801f`，AI 工具与前沿 `#3a92d6`。明度、彩度、色盲区分度和对比度全部通过。文字一律用正文色，不用系列色。
- 热力图用单一琥珀色的深浅表示分钟数。
- 有「数据表」开关，可以看同一份数据的表格。
- 共享主题（AI量化交易系统）同时计入两个目标，图注里写明。
- 「本周 / 本月 / 全部」只是一个切换，不新开页面。

**刻意不做**：排行、和别人比、徽章、打卡奖励。Streak 只呈现，不做提醒（POSITIONING §6 把 Streak 和通知列为不做）。

### 2.3 资料（视图，v2 新增；吸收 v1 的笔记修正层）

│ │▤ 趋势交易全攻略      已整理    │ │      理由… [按这样保存][看这次的全部 4 处]│ │
│ │▤ 双均线交易系统      已整理    │ │抽出的概念 · 19（按笔记分组，带掌握点）  │ │

│                                  └────────────────────────────────────┘ │
│        ╞═ ● 丢新资料，或问「这份讲了什么」…  [资料·AI量化…] [＋] [↑] ═╡        │
└──────────────────────────────────────────────────────────────────────┘
```

**列表行**：类型图标、标题、状态（整理中带转圈 / 待确认是紫色虚线 / 已整理是灰色）、「识别为 <类型> · <一句话>」、归到的目标（带颜色点）、概念数、丢进来的时间。两组筛选：按状态、按类型。

**详情区**，按整理流水线的顺序从上往下：

1. **智能体识别**：是什么、讲什么、学习路线、和已有资料的关系。原型里「讲什么」和「学习路线」取自笔记学习主页的一句话总结和路线，不是编的。视频还没读完时，「讲什么」写「还在读字幕，读完再写，不先猜」。
2. **整理过程**：读取 → 识别 → 抽概念 → 归类 → 编译星图。每一步有状态和一句说明，对应 Item.pipeline（POSITIONING §3.2）。想法不抽概念，那一步显示「不适用」。
3. **归属**：目标 chip 多选、置信度、理由。待确认时出现「按这样保存」和「看这次整理的全部 4 处」（进入调整归类层）。已自动接受的写明「高于阈值 0.85，已自动接受；随时可以改」。
4. **抽出的概念**：按笔记里的分组排列，每个概念带掌握点。点击可以改名、隐藏、改归属、置顶重要性。这就是 v1 的笔记修正层，改过的标「你改过 / 你置顶」，写成 Override，不改原笔记。
5. **底部操作**：在全景中看、潜航学习、打开原笔记、重新整理、撤销这次整理。

**不同类型的资料**：

| 类型 | 识别后去哪 | 原型里的例子 |
| --- | --- | --- |
| 视频链接 | 解析字幕 → 抽概念 → 归类 → 新主题 | 「趨勢轉折與發展的關鍵步驟」，整理中 |
| 课程笔记（Obsidian 主题目录） | 编译 → 归类 → 新主题 | 三份示例笔记 |
| 想法（一句话） | **不拆出新概念**，只挂到已有的星，显示在那颗星的「💭 我的思考」里（POSITIONING §2.7） | 「均线拐头前，能不能用抵扣价提前判断？」，待确认挂到「抵扣价」 |
| 文章 / PDF | 下一轮。筛选里显示「文章 0」，入口先占位 | — |

和调整归类层的关系：资料视图管**每一份资料**，调整归类层管**某一次整理**（ChangeLog）。两边互相能跳过去，写入的是同一份 Override。

### 2.4 学习全景图（视图，取代 v1 的星图总览）

**用途**：一屏看完我学的全部东西：目标 → 主题 → 分组 → 概念，学到哪、哪里连着、哪里是空的、下一步去哪。它是 agent 整理结果的可视化，用户不用手动搭。

```text
┌──────────────────────────────────────────────────────────────────────┐
│ [全景|目标|主题|概念] 滚轮缩放·点星座潜航                ┌ 摘要栏 ──────────┐│
│        目标                     目标                    │36 颗星·3 主题·2 目标│
│      量化交易               AI 工具与前沿                 │已学18·回忆11·掌握3  │
│  [双均线 4/5]                     ③──前视偏差            │量化交易 ▓▓▒▒░░░ 18/36│
│   ①抵扣价 ⋯⋯                MCP      ╭缺口╮              │AI 工具  ▓▒▒░░░  8/19 │
│      ⋯同名候选⋯              ⋯   ⋯    │风险与 │           │缺口：动作依据 0/5    │
│        ╭缺口·动作依据╮  ⋯⋯⋯        │执行0/4│           │     风险与执行 0/4   │
│        │ ②关键性波动  │ 系统与策略   ╰─────╯             │待确认的关联 3        │
│        ╰───────────╯   [AI量化 8/19 也属于量化交易？]      │下一步 ①抵扣价 ②关键… │
│  [趋势交易全攻略 6/12]                                    │图例                │
│     ┌ 提示卡（单行）┐ ╞═ Agent 栏（在星图区居中）═╡        └──────────────────┘│
└──────────────────────────────────────────────────────────────────────┘
```

**星图区**：

| 编码 | 含义 |
| --- | --- |
| 星云分区 + 大号淡色名字 | 目标 |
| 星座 + 底部标签（已学/总数） | 主题；点击潜航 |
| 星座内聚成小团（v2） | 笔记里的分组，例如「回测与验证」「风险与执行」。分组取自学习主页的「核心概念卡」表 |
| 亮度 / 大小 | 掌握 / 重要性（同 v1） |
| 琥珀实线脉冲环 | 今天到期复习 |
| 紫色虚线 | 待确认：主题多归属的系绳、跨主题同名候选（抵扣价 ≈ 抵扣价原理；双均线系统 ≈ 双均线系统（MA+EMA））、agent 提议的关联（金叉策略 ↔ 双均线系统） |
| **珊瑚色虚线圈 + 「缺口 · 分组名 0/n」（v2）** | **缺口**：一整组（至少 3 颗）全都没学。示例里是趋势交易的「动作依据 0/5」和 AI 量化的「风险与执行 0/4」 |
| **金色点线 + ①②③（v2）** | **下一步**：和「今天」的前三条一致（抵扣价 → 关键性波动 → 前视偏差） |

**摘要栏（右侧，v2）**：把星图上的信息用文字再说一遍，也方便不看图的人。
- 总数：颗星、主题、目标；已学、回忆过、已掌握、未归属。
- 每个目标一条分段条（掌握 / 回忆过 / 看过 / 未学），带数字。
- **缺口**：分组名、0/n、所属主题，再加一句为什么要紧。例如「含全片题眼『关键性波动』，已排进今天」「前一块『回测与验证』还剩 4 颗没学」。
- **待确认的关联**：点击进入调整归类层。
- **下一步**：与「今天」一致，点击潜航。
- 图例。

**缩放**：全景 → 目标 → 主题 → 概念。主题和概念两级就是现有星图潜航（§2.5），全景和目标两级是新的。原型只做了全景一级，点「目标」会提示未实现。

缺口和下一步的计算规则都是确定的，不调用模型：
- 缺口 = 某个分组全部未学且至少 3 颗。
- 下一步 = TodayPlan 的前几条。
- 关联只来自笔记明写的内容，或者用户确认过的提议（裁决 5、7）。agent 提议的关联在确认前不进学习路线。

### 2.5 星图潜航（同 v1）

保留现有页面：节点聚焦、主卡、环绕卡、原地展开面板、时间轴。在此基础上增加：
- 面包屑：`全景 › 量化交易 › 双均线交易系统`。
- 主卡底部的掌握条。
- 到期标记。
- 「相关」里显示跨主题候选。
- 时间轴上移，避开 Agent 栏。
- Agent 栏显示当前场景。

### 2.6 离星回忆（同 v1）

离开一颗看过的星时，在星旁边出一题（或者「记得 / 忘了」两个键）。可以跳过。结果写成 LearningEvent，星当场变亮。**统计层的回忆正确率就来自这里**。

### 2.7 调整归类（覆盖层，同 v1）

一组按钮卡：「这次整理了 4 处，1 处想听你的」，分为待确认 → 合并候选 → 已自动接受。入口有：提示卡「看看」、全景里的虚线和「待确认的关联」、资料详情「看这次整理的全部 4 处」。底部的「在资料里细调」直接跳到那份资料（v1 是跳到笔记抽屉）。

### 2.8 Agent 栏与回答卡（同 v1）

- 栏的位置和样式不变。全景图里栏在左侧星图区居中，不压摘要栏。
- 场景 chip 会显示「资料 · AI量化交易系统」「全景 · 全部目标」这样的上下文。
- 回答卡只引用 TodayPlan 和学习记录。
- 新增可以答的问题：「我这周学了多少」打开统计层；「这份资料讲了什么」引用资料的识别结果。

## 3. 导航

1. **顶部三个词**：今天 · 全景 · 资料。「资料」右上角的紫点表示有待确认。
2. **点内容就是导航**：
   - 统计条 → 统计层；
   - 智能体整理卡 → 资料；
   - 目标卡 → 全景；
   - 今日卡、全景里的星 → 潜航；
   - 虚线、待确认 → 调整归类；

4. **键盘**：`/` 聚焦栏，`Esc` 逐层后退（覆盖层 → 视图；潜航 → 全景）。
5. 面包屑只在潜航里出现。

## 4. 首次使用与空状态

### 4.1 首次使用

1. **空**：一颗种子星、「把在学的东西丢进来」，以及能丢的类型：视频链接、笔记文件夹、一段想法（v2 起列为可用）、文章 / PDF（下一轮）。另外有三条承诺，Agent 栏可以拖入。
2. **整理中**：每份材料有四段进度，并加一行「识别为：课程笔记 · 源自 LEI 视频课 10:41」（v2）。右边是目标提议卡，标明模拟组件。
3. **完成**：进入「今天」，出现提示卡。

### 4.2 空状态

| 情形 | 显示 |
| --- | --- |
| 有材料、没确认目标 | 「今天」只显示一张提议卡和未归属桶 |
| 统计：刚开始用 | 统计条只显示「已学 0/N」，其他读数显示「—」；统计层写「学满 3 天后才有趋势」，热力图里开始使用前的日子用虚线格 |
| 统计：今天还没学 | 连续天数照常显示，下面注「今天还没开始」，不催 |
| 资料：空 | 「还没有资料」+ 能丢什么，和首次使用一致 |
| 资料：整理失败 | 状态「失败」+ 原因（Item.pipeline = failed(reason)）+ [重试] [先放未归属] |
| 全景：只有一个目标 | 不画星云分区，摘要栏照常 |
| 全景：没有缺口 | 摘要栏写「没有整块没学的部分」 |
| 无模型密钥 | 归类走 null / folder 基线，资料视图的组件名显示「按文件夹归类（没调用模型）」 |

## 5. 视觉规范

**沿用 `star-dive.css`**：`--bg*`、`--amber*`、`--cyan`、`--ink*`、`--glass`、玻璃卡、`.tag`、`.chip`、`.chip.ts`、`.btn.pri`、星的 halo / core 结构、bloom 入场动画。

| 名称 | 值 | 用途 |
| --- | --- | --- |
| `--pending` | `#c9b6ff` 紫，虚线 | 待确认、候选 |
| 缺口珊瑚 | `rgba(255,150,130,.5)` 虚线（v2） | 只用于全景里的缺口 |
| 下一步金 | 琥珀点线 + 实心编号（v2） | 只用于全景里的下一步路线 |
| 用户决定绿 | `rgba(134,255,190,…)` | 你改过、你置顶，回忆成功 |
| 模拟橙 | `#ffd0b0` | 模拟组件、模拟回答、示例数据，强制显示 |
| 图表系列色（v2） | 量化交易 `#c4801f`，AI 工具与前沿 `#3a92d6` | 只用于统计层的图表。比界面用的琥珀和青色暗一档，是为了在深色底上通过 dataviz 校验 |
| 热力图 | 琥珀单色 5 档（无、≤20、≤35、≤45、>45 分钟） | 统计条、统计层 |

**规则**：
- 虚线 = 还没定，实线 = 已定。
- 颜色只表示：目标归属、状态（待确认 / 缺口 / 你改的 / 模拟）、掌握。
- 一屏最多一张助手卡。

## 8. 原型说明与已知限制

- **打开方式**：双击 `prototype.html`。右下角「原型页面」列表可以跳到 10 个屏，也可以直接用地址：
  - `#first`：首次使用
  - `#organizing`：整理中
  - `#home`：今天
  - `#stats`：学习统计
  - `#library`：资料
  - `#adjust`：调整归类
  - `#panorama`：全景
  - `#dive`：潜航
  - `#recall`：离星回忆
  - `#ask`：助手回答

  旧地址 `#map` 和 `#notes` 分别跳到全景和资料。带 `?shot` 参数时隐藏页面列表并关闭动画。
- **可以点的流程**：
  - 今天：统计条 → 统计层（可切换数据表）；智能体整理卡 → 资料。
  - 资料：点任一行，详情切换。在 AI量化 的详情里，可以切换目标、按这样保存，或进入调整归类。在「想法」的详情里点「挂上去」，状态变成已整理，顶部紫点随之减少。
  - 全景：右栏的缺口、下一步 → 潜航；待确认的关联 → 调整归类。
  - 其余流程同 v1。
- **限制**：
  - 静态单文件，没有后端，刷新会重置。
  - 统计层的「本周 / 本月」切换和资料视图的筛选只是样子，不会真的过滤。
  - 全景只做了全景一级缩放。
  - 潜航只做了「抵扣价」一颗星。
  - 星座布局按种子随机生成，真实实现应沿用 `scene.ts`。
  - 只按桌面 1440×900 调过。
  - 图表的悬停提示用的是浏览器原生 title，真实实现应换成 crosshair + 浮层。
  - `shots/` 仍是 v1 截图，v2 按要求没有重拍。
