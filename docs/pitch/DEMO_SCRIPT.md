# 3 分钟演示脚本

原则：**一上来就演示**，先让人看到结果，再讲为什么。

## 开场前准备（30 秒，演示开始前完成）

```bash
cd server && npm run demo
```

浏览器打开 `http://localhost:5173/#/today`，全屏。如果要演示助手，先在 `http://127.0.0.1:4000/settings` 填好模型密钥。

---

## 0:00–0:20 · 第一屏就是结论

**画面**：今天视图。

> 「这是一个学生今天打开学习应用看到的第一屏：**今天学 5 件事，约 10 分钟**。
> 注意每张卡下面的『为什么』，比如『昨天离星回忆选了忘了，按 1 天间隔今天到期』。
> 这些理由全部来自TA 自己的学习记录，没有一句是模型编的。」

## 0:20–0:45 · TA 学的东西长什么样

**操作**：点顶部「全景」。

> 「这是 TA 过去三周的全部学习内容：三个目标、三个主题、31 颗知识星。
> **越亮代表掌握得越好**。珊瑚色虚线圈是**缺口**：『优化方法』这一组 4 颗星，TA 一颗都还没学。
> 金色数字是建议的下一步。」

**操作**：拖一下画布，再拖一颗星，展示星图是活的。

## 0:45–1:30 · 让人想试的瞬间

**操作**：点「量化交易」星团，进入星图潜航，点「凯利公式」这颗星。

> 「点一颗星，它飞到中央，周围是按知识**形状**生成的卡片：定义、对比、流程，还有一张『公式与参数』。」

**操作**：打开「公式与参数」卡，**慢慢拖动「胜率」和「盈亏比」滑块**。

> 「凯利公式不是一段要背的文字。拖动滑块，**全凯利**和**分数凯利**两条仓位曲线实时变化。
> 把盈亏比往下拖，建议仓位越来越小。凯利公式的直觉就在这里：优势越小，下注越少；没有优势，就**不该下注**。
> 这张卡是模型看完 Ed Thorp 的视频后生成的，曲线由应用实际计算。」

**操作（已配置模型时）**：在助手里问「为什么现在仓位是这个数？」

> 「助手知道我此刻停在哪张卡、滑块是多少，所以它解释的是**我眼前这条曲线**，不是泛泛而谈。」

## 1:30–1:50 · 复习藏在探索里

**操作**：关闭卡片，点「返回星图」。

> 「离开这颗星时，它只问一句：还记得吗？」

**操作**：点「记得」，再回到全景。

> 「就这一下，这颗星的掌握度更新了，下次复习按 1 / 3 / 7 / 14 / 30 天的间隔自动排好。不用出题，也不用打卡。」

## 1:50–2:30 · 智能体替你整理，但你说了算

**操作**：点「资料」，选中「凯利公式与仓位管理」。

> 「TA 丢进来的每一份东西，智能体都摊开给你看：识别成什么、讲什么、学习路线、抽出 8 个概念、归到哪个目标。
> 还有**置信度 0.95 和理由**。高置信的自动接受，低置信的等你确认，每次整理都能一键撤销。」

**操作**：点「打开笔记」。

> 「背后是一份完整的 Obsidian 风格笔记：双链、反链、公式、视频时间戳，点时间戳回到视频的那一秒。」

## 2:30–3:00 · 收尾：为什么值得持续用

> 「我们做 UlearnBetter，是因为我们自己就是这样学习的：同时学课业、量化和 AI，视频看了一大堆，两周后忘光。
>
> 它的成本结构也让它能长期用下去：**加工一个新视频才调用模型**，每分钟视频约 1 万 token；**日常学习、复习、排计划全部用规则计算，不调用模型**。所有数据存成本地文件，不锁定在我们这里。
>
> 下一步是 FSRS 复习引擎、PDF 输入和桌面常驻的学习伙伴。」

## 备用演示点（时间多时加）

| 想展示 | 去哪 |
| --- | --- |
| 学习统计 | 今天视图右上角统计条 → 「统计」 |
| 换一个输入 | 把一个 YouTube / B 站链接贴进助手输入框（需配置模型） |
| 模型热切换 | `127.0.0.1:4000/settings`，切换模型后点「测试连接」 |
| 工程质量 | 终端运行 `cd server && npm test`，91 个后端测试几秒跑完 |
