# 价值、付费与成本

## 1. 为什么值得持续使用

笔记工具常见的结局是：前一周热情满满，一个月后不再打开。UlearnBetter 的每个机制都在回答同一个问题：**明天为什么还要打开它？**

| 机制 | 用户感受到的 | 已实现 |
| --- | --- | --- |
| **今日计划** | 打开就知道今天学哪 5 件事，不用自己排 | `server/src/record/derive/today.mjs` |
| **到期复习** | 昨天忘了的，今天会再出现；记住的，间隔越拉越长（1 → 3 → 7 → 14 → 30 天） | `derive/mastery.mjs` |
| **星图点亮** | 学过的星会亮起来，进步看得见；缺口也一目了然 | `views/panorama/` |
| **连续天数与统计** | 本周学了多少分钟、连续几天、回忆正确率多少 | `derive/stats.mjs` |
| **资产越积越厚** | 目标、修正、想法、反思、回忆记录都留在自己手里，用得越久越离不开 | `RECORD_DATA_DIR` 下的 JSON / JSONL 文件 |
| **越用越懂你** | 拒绝过的归类不会再提；你的每次修正都会保留下来，可以作为训练更准的整理器的数据 | `derive/overlay.mjs`、`organizers/` |
| **随时有人陪** | 常驻的学习小人，问什么都结合你正在看的那张卡来回答 | `assistant/ui/` |

另外，**数据不锁定**也让人更愿意长期投入：所有记录都是本地文件，目录结构按 Obsidian vault 设计，笔记就是普通 Markdown。用户哪天离开，东西也能全部带走。

## 2. 谁付费

| 付费方 | 买的是什么 | 形态 |
| --- | --- | --- |
| **个人学习者**（核心） | 省下“看完就忘”的时间成本；每天一份有理由的学习计划 | **免费版**：本地运行，自带模型密钥（已支持 5 家模型和任意 OpenAI 兼容端点）。**订阅版**：托管模型额度（免配置）、多设备同步、移动端复习 |
| **知识区创作者 / 课程方** | 把自己的视频课程一键变成可交互的星图，作为课程的增值交付，提高学员完课率 | 按课程或学员数收费；生成一次，所有学员复用 |
| **学校与培训机构** | 学生端同上；教师端能看到全班的“缺口”分布 | 机构授权（下一阶段） |

免费版对我们几乎没有边际成本（见下文），所以可以放心地靠免费版获客，再用托管额度和同步服务转化付费。

## 3. 成本几何

### 3.1 成本结构：只有“加工新内容”花钱

| 环节 | 是否调用模型 | 成本 |
| --- | --- | --- |
| 视频解析（元数据、章节、字幕） | 否 | 0（`yt-dlp`；无字幕时可选本地语音识别） |
| **生成学习笔记** | **是** | 见 3.2，**每个视频只付一次** |
| 笔记编译成星图 | 否 | 0（确定性编译器） |
| 资料识别与归类 | 可选 | `folder` 整理器为 0；`llm` 整理器每份资料一次短调用，只发送标题、一句话总结和概念名 |
| **每天学习：今日计划、掌握度、复习排期、统计、全景** | **否** | **0**，全部是公开的确定性规则 |
| 学习助手问答 | 是，按需 | 每次只携带当前场景快照；每次请求最多 8 次工具调用（`ASSISTANT_MAX_TOOL_CALLS`），费用有上限 |

**结论：用户每天的核心学习循环零模型成本。** 用得越久，成本占比越低：内容只需加工一次，复习可以重复很多次。

### 3.2 实测：加工一个视频要多少 token

数据来自预置数据的真实生成日志（`samples/demo/notes/*/*.generation.json`，逐次记录了 request id 和 token 数）：

| 主题 | 视频 | 时长 | 调用次数 | 输入 token | 输出 token |
| --- | --- | --- | --- | --- | --- |
| 神经网络入门 | 3Blue1Brown × 3 | 52.0 分钟 | 32 | 239,431 | 41,890 |
| Git 版本控制 | Fireship × 2 | 20.4 分钟 | 28 | 232,263 | 41,836 |
| 凯利公式与仓位管理 | Financial Wisdom × 1 | 8.2 分钟 | 21 | 154,240 | 43,223 |
| **合计** | **6 个视频** | **80.6 分钟** | **81** | **625,934** | **126,949** |

折算下来：**每分钟视频约 7.8k 输入 token + 1.6k 输出 token**，一个 10 分钟的视频约 7.8 万输入 + 1.6 万输出。

这是追求质量的上限配置：先做整体规划，再逐章、逐张概念卡、逐份实操清单单独生成，最后标注公式卡，每个文件一次调用。应用内的视频流水线（`server/src/record/video.mjs`）改为**每个视频一次结构化调用**（失败才重试一次），转写输入上限 12 万字符，调用次数和输入量都更少。

### 3.3 换算成钱

```text
单个视频成本 ≈ 视频分钟数 × (7.8k × 输入单价 + 1.6k × 输出单价)
```

> 以“输入 1 元 / 百万 token、输出 4 元 / 百万 token”这一**示例单价**计算：
> 10 分钟视频 ≈ 0.078 + 0.064 ≈ **0.14 元**，一门 10 小时的视频课 ≈ **8.5 元**，并且只付一次。
> 实际价格按所选模型替换。应用支持任意 OpenAI 兼容端点，可以按预算选模型。

### 3.4 运行成本

- **单进程、无数据库、无 GPU**：后端是一个 Node 进程，数据是本地文件；
- **本地优先**：免费版完全跑在用户自己的电脑上，平台侧没有服务器成本；
- **托管版**按“模型额度 + 同步存储”计费，模型是唯一的主要变动成本，而它只在加工新内容时发生。

## 4. 可持续的技术底座

- **组件可替换**：整理器放在接口后面（`null / folder / llm`），模型提供方可以热切换。哪家模型更便宜、更好，换上就行，用户数据不受影响；
- **派生可重算**：星图、计划、统计都能从“材料 + 用户决定”重新算出来。升级算法时（比如换成 FSRS），历史学习记录可以直接复用；
- **质量有保障**：261 个自动化测试、三条 CI 流水线、17 份共享 JSON Schema，保证迭代的时候不会把已有功能改坏。
